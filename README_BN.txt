MOVIE HUB BD — STARTER ZIP

এটি একটি starter template, সম্পূর্ণ publish করা ওয়েবসাইট নয়।

ফাইল:
- index.html: ওয়েবসাইটের মূল পেজ
- content/movies.json: মুভির তথ্য
- admin/index.html: Admin পেজের entry
- admin/config.yml: CMS configuration

গুরুত্বপূর্ণ:
1. ZIP extract করে সব ফাইল GitHub repository-তে upload করতে হবে।
2. Netlify-তে repository connect করে deploy করতে হবে।
3. Admin login কাজ করাতে GitHub OAuth/authentication আলাদাভাবে configure করতে হবে।
4. config.yml-এ YOUR_GITHUB_USERNAME/YOUR_REPOSITORY_NAME বদলে নিজের তথ্য দিতে হবে।
5. শুধু আইনসম্মত/অনুমোদিত download link ব্যবহার করুন।
